# Yakushi Control Deck v1.2.1

v1.2.1 is a small navigation and wallpaper-library polish release.

## Changes

- Sidebar navigation now opens every page at the top instead of carrying over the previous page's scroll position.
- Wallpapers opens on `~/Documents` by default.
- The `Documents` root filter includes nested directories, so a wallpaper library can stay organized in subfolders.
- `~/Pictures` remains indexed and available from the folder filter.

No existing Waybar, Rofi, SDDM, Hyprland, Kitty, Auto Color, or Nautilus settings are replaced by the hotfix.
