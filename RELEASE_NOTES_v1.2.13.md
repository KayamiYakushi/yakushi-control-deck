## Yakushi Control Deck v1.2.13

A small but important power-menu cleanup release.

### Changes

- Removed the obsolete theme/colorizer button from the Waybar power menu.
- Power menu now contains exactly five actions: Lock, Suspend, Logout, Reboot and Shutdown.
- Added a dedicated horizontal Rofi power-menu layout that follows the current Yakushi palette and opacity.
- Existing power-menu files are backed up before replacement during installation.

No appearance controls were removed from Control Deck; Theme Studio and Auto Color remain the canonical place for desktop theming.
