# Yakushi Control Deck v1.2.9

This release repairs empty Fastfetch configs and adds theme-aware Hyprland window frame and shadow customization.

## Highlights

- Automatic repair for an empty `~/.config/fastfetch/config.jsonc`
- Fastfetch Studio `RESET SAFE DEFAULT` action
- Theme-follow or custom active/inactive window border colors
- Configurable shadow color and opacity
- Configurable shadow size, falloff, X/Y offset and scale
- FOLLOW mode tracks Theme Studio and Auto Color
- Managed Hyprland config blocks roll back if a new config error appears
